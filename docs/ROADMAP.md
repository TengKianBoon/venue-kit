# Roadmap

| Stage | Item | Why |
|---|---|---|
| Next | Email login via SMTP (e.g. Brevo free tier) | Guests without Google accounts |
| Next | WhatsApp OTP login | WhatsApp is the main channel in SEA hospitality |
| Next | Multi-tenant mode: `venue_id` on every table, with RLS per venue | Many venues on one project, one admin console |
| Later | POS spend sync | Remove manual spend logging |
| Later | Retention analytics (visit frequency, lapsed members, voucher ROI) | Turn member data into decisions |
| Later | AI assistant for the owner: "make a Friday promo for students" drafts a promotion for approval | Owner-side content generation with a human in the loop |
| Later | Automated daily backup to the owner's Google Drive | Removes the weekly manual step |
